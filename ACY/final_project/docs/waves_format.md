# 웨이브 데이터 포맷 명세 (`project/src/waves.txt`)

R2 요건에 따라 적 출현 배치를 코드가 아닌 데이터 파일(`waves.txt`)로 정의합니다.

## 1. 문법 규칙
- 인코딩: UTF-8, 줄바꿈은 LF(`\n`) 또는 CRLF(`\r\n`) 모두 허용합니다.
- **빈 줄 / 공백 줄**: 무시합니다.
- **주석**: 앞 공백을 제외하고 `#` 으로 시작하는 줄은 무시합니다.
- **웨이브 선언**: `wave <번호>`
  - `<번호>` 는 1 이상의 정수여야 합니다. (예: `wave 1`)
- **적 배치**: `enemy <종류> <x> <y>`
  - 반드시 `wave` 선언 아래에 위치해야 합니다.
  - `<종류>` 는 영문/숫자/밑줄로 구성된 식별자입니다. (예: `grunt`)
  - `<x>`, `<y>` 는 숫자(좌상단 좌표)입니다.

### 예시 (`waves.txt`)
```text
# 웨이브 1: 기본 편대
wave 1
enemy grunt 60 60
enemy grunt 120 60

# 웨이브 2
wave 2
enemy grunt 80 80
```

## 2. 오류 처리 규칙 (`gmatch` 조용한 무시 금지)
`WaveParser.parse(text)` 는 줄 번호(`lineNo`)를 추적하며 형식이 어긋난 줄을 만나면 즉시 `error("line <번호>: <이유>")` 를 발생시킵니다.
- `wave` 앞에 `enemy` 가 나온 경우
- `wave` 의 번호가 양의 정수가 아니거나 여분 토큰이 있는 경우
- `enemy` 인자 개수가 3개(`<kind> <x> <y>`)가 아니거나 `x`, `y` 가 숫자가 아닌 경우
- 알 수 없는 키워드로 시작하는 줄
- 파싱 결과 웨이브가 1개도 없거나, 적이 0기인 빈 웨이브가 있는 경우
