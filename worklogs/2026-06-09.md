### 3. 터미널 경로 실행 오류 해결

### 4. "다시해줘" 피드백에 따른 재리팩토링 및 안정성 강화
- **순환 참조(Circular Dependency) 방지**: 이전 작업 시 모듈 상호 로딩 문제(skills.lua가 top-level에서 enemy.spawner를 require할 때 발생하는 로딩 루프 현상)로 인해 코드가 정상적으로 컴파일되지 않았던 점을 진단.
- **로컬 동적 로딩 적용**: `skills.lua` 내 레이저 및 자기장 충돌 처리 블록 내부에서 필요한 순간에만 `local EnemyModule = require("enemy.spawner")`를 동적 로드하도록 변경하여 순환 참조를 완전히 우회.
- **재검증 완수**: `run.bat`를 다시 구동하여 게임 실행 중 튕김 현상이나 문법/모듈 로딩 오류 없이 정상 구동됨을 검증 완료.

### 9. 시작 메뉴에서 메테오 스킬 선택 시 낙하하지 않던 버그 해결 완료
- **진단**: `player.lua` 모듈의 플레이어 데이터 초기화 함수 `Player.init`에서 지원하는 스킬 개수가 이전 6개 기준으로 하드코딩(`skillLevels = { 0, 0, 0, 0, 0, 0 }`, `skillIndex <= 6` 조건 검사)되어 있어, 7번째 스킬인 메테오를 골라도 플레이어의 스킬 레벨에 할당되지 않아 메테오 스킬이 가동되지 않는 문제를 발견.
- **수정**: [player.lua]의 `skillLevels` 배열 길이를 7로 확장하고 상한값 조건 검사 영역을 `skillIndex <= 7`로 업데이트하여 7번째 메테오 스킬이 시작 시 올바르게 레벨 1로 초기화 및 활성화되도록 패치.
- **검증**: 게임을 다시 기동하여 메테오 스킬을 첫 스킬로 선택해 시작할 시 주기적으로 하늘에서 운석이 정상 낙하하며, 지면 충돌 시 화면 쉐이크와 4레벨 시 불장판 생성 효과가 완벽히 적용되는 것을 플레이를 통해 최종 확인 완료.

  - `HUD.drawMetaUpgrade(game)`를 통해 이전 세션에서 획득한 누적 점수(`TOTAL SCORE`)를 사용하여 플레이어의 기본 스펙을 영구적으로 구매 및 업그레이드할 수 있는 상점 창 구현.
  - **영구 강화 4종 스펙**:
    1. **Fortified Hull (HP +10)**: 기본 1000P ➡️ 레벨당 +500P씩 증가
    2. **Thruster Output (속도 +3%)**: 기본 1200P ➡️ 레벨당 +800P씩 증가
    3. **Reactor Overload (피해 +2)**: 기본 1500P ➡️ 레벨당 +1000P씩 증가
    4. **Gravity Core (자석 범위 +15)**: 기본 1000P ➡️ 레벨당 +600P씩 증가
  - 각 강화 항목의 현재 레벨(최대 5레벨), 필요 점수, 구매 불가능 시(점수 부족 혹은 만렙 달성 시) 자동으로 회색 비활성화되는 예외 처리 적용.
  - `Player.init`에서 이 영구 강화 레벨들을 수신하여 플레이어의 최초 스폰 시 최대체력, 이동속도, 기본 무기 피해량, 자석 감지 범위에 가중 배율/합산을 더해 세팅되도록 확장 연동 완료.
- **로컬 세이브 파일 영구 지속 기능 ([main.lua])**:
  - `love.filesystem` 모듈을 연동하여 `save.txt` 파일에 누적 점수(`totalScore`), 4개 강화 레벨, 설정 온오프 정보를 텍스트 `key:value` 구조로 쓰고 읽는 `game.saveGame()`, `game.loadGame()` 모듈 완성.
  - 게임 플레이 중 죽어서 게임오버가 될 때 세션에서 획득한 `game.score`를 persistent `totalScore`에 합산하고 즉시 파일에 저장해 주는 정산 파이프라인 수립 완료.
- **런타임 검증**: 게임이 메인 메뉴로 정상 부팅되고 설정 토글 기능이 정상 적용되며, 획득한 스코어로 상점에서 체력을 강화하여 다음 판에 실제 최대체력이 110으로 늘어난 채 게임이 구동되는 전체 흐름이 문법 에러 없이 완벽히 동작함을 플레이 검증 완료.

### 14. 영구 강화 상점 탭 기반 페이지 전환 기능 구현 완료
- **탭 레이아웃 적용**: 상점 화면의 가로 폭과 글자 크기를 키우기 위해, 상점 상단에 `[ ACTIVE SKILLS ]`와 `[ PASSIVE STATS ]` 탭을 추가. 클릭 시 활성화된 페이지만 그리도록 설계.
- **가로 폭 및 텍스트 폰트 확장**:
  - 카드 상자 크기를 기존 `285x46`에서 `340x60`으로 대폭 키우고 Y 간격을 70px로 벌려 텍스트 배치 공간 확보.
  - 항목별 타이틀 폰트 크기를 `13`에서 `15`로, 설명 및 레벨 텍스트 폰트 크기를 `10`에서 `11`로 상향하여 가독성 개선.

- **검증 완수**: `run.bat` 구동 테스트 시 페이지 탭 전환 시 화면 갱신이 자연스럽게 일어나며, 각 탭 내 항목의 텍스트가 매우 선명하고 크게 출력되고, 점수 차감 및 로컬 세이브 데이터 저장이 올바르게 진행됨을 최종 확인.
