# 목적

프로젝트의 기술 문서를 작성할 때 이 스킬을 사용합니다.

## 절차

1. 문서 목적과 대상 독자 식별
2. 문서 구조 설계
3. 내용 작성 (설치, 실행, 아키텍처 등)
4. 예제 및 다이어그램 추가
5. 검토 및 수정

## 출력 형식

- 문서 종류 (README, 보고서 등)
- 문서 구조
- 작성된 내용
- 예제 코드
- 다이어그램 (필요시)
