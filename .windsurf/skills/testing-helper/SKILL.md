# 목적

게임의 기능과 성능을 검증하는 테스트 케이스를 작성할 때 이 스킬을 사용합니다.

## 절차

1. 테스트 대상 기능 식별
2. 테스트 케이스 설계 (정상 케이스, 엣지 케이스)
3. 테스트 코드 작성
4. 테스트 실행 및 결과 확인
5. 실패 시 디버깅 및 수정

## 출력 형식

- 테스트 대상 기능
- 테스트 케이스 목록
- 테스트 코드
- 실행 결과
- 실패 시 원인 및 해결 방법
