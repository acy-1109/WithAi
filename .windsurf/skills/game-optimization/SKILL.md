# 목적

게임 성능 최적화를 위한 기술들을 구현하고 적용할 때 이 스킬을 사용합니다.

## 절차

1. 성능 병목 지점 식별 (프로파일링)
2. 적합한 최적화 기술 선택
3. 최적화 구현 (Object Pooling, Spatial Hashing 등)
4. 벤치마크로 성능 향상 확인
5. 정확성 테스트 (최적화로 인한 버그 없는지 확인)

## 출력 형식

- 최적화 전후 성능 비교
- 구현한 최적화 기술 설명
- 벤치마크 결과
- 검증 단계
