# Roguelike Survivor - 설계 문서

## 게임 컨셉

로그라이크의 절차적 생성과 뱀파이어 서바이벌의 웨이브 기반 생존 요소를 결합한 게임입니다.

## 핵심 메커닉

### 1. 절차적 던전 생성 (향후 구현)
- BSP (Binary Space Partitioning) 기반 방 분할
- Cellular Automata 기반 동굴 생성
- Random Walk 기반 복도 연결
- Perlin Noise 기반 자연스러운 지형

### 2. 웨이브 기반 적 스폰
- 시간 경과에 따른 적 강도 증가
- 다양한 적 타입 조합
- 확률적 스폰 위치

### 3. 경험치/레벨업 시스템 (향후 구현)
- 적 처치 시 경험치 획득
- 레벨업 시 스킬 선택
- 랜덤 스택 풀

### 4. 진행 시스템 (향후 구현)
- 난이도 곡선
- 업그레이드 트리
- 영구 사망

## 게임 루프

```
시작
  ↓
던전 생성
  ↓
웨이브 시작
  ↓
적 스폰 → 플레이어 생존 → 경험치 획득
  ↓
웨이브 종료
  ↓
레벨업/스택 선택
  ↓
다음 웨이브 또는 던전 이동
  ↓
사망 또는 클리어
```

## 밸런싱

### 초기 밸런스
- 플레이어 체력: 100
- 적 데미지: 1
- 무적 시간: 1초
- 적 스폰 간격: 2초
- 최대 적 수: 10

### 난이도 조절 (향후 구현)
- 시간 경과에 따른 적 속도 증가
- 웨이브마다 적 체력 증가
- 새로운 적 타입 추가
